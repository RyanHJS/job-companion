# Resume Proposal Diff

Use this as the rationale ledger for a proposal run. Detailed wording review
uses the paired full-resume Markdown snapshots and their Git-style diff. Include
changed points only; do not reproduce the full resume here.

| Before | After | Why |
|---|---|---|
| Existing wording, or `New bullet` | Exact proposed wording | `P-001`, target location, requirement addressed, evidence basis, and reason |

Wait for the user to approve or correct the rows and Markdown diff before
invoking `resume-assembly`. Do not edit the original resume source while
creating these artifacts.

Link or append the recruiter and technical-manager assessments produced from
`templates/proposal-perspective-review.md`.
